# ADR-004: Выбор клиента Apache Kafka (`aiokafka`)

**Статус:** Accepted

## Контекст

Сервису требуется асинхронный Kafka producer и consumer для Python 3.12+ с поддержкой семантики at-least-once, ручного коммита смещений (`enable_auto_commit=False`) после завершения транзакции в PostgreSQL и корректного завершения работы при остановке процесса.

## Решение

Использовать библиотеку **`aiokafka`** для продюсера, консьюмера и администрирования топиков в пакете `infrastructure/messaging/kafka/`.

## Рассмотренные альтернативы

| Вариант | Преимущества | Недостатки |
|--------|--------------|------------|
| **`aiokafka`** | Нативная поддержка `asyncio`; единая модель исполнения с FastAPI и async SQLAlchemy; чистая установка без внешних C-зависимостей | Меньше низкоуровневых утилит по сравнению с экосистемой `librdkafka` |
| **`confluent-kafka`** | Зрелая библиотека на базе `librdkafka` | Базовый API синхронный (требует обёрток с потоками для `asyncio`); дополнительные системные зависимости в контейнерах |

## Последствия

- Все операции публикации, создания топиков (`AIOKafkaAdminClient`) и чтения (`AIOKafkaConsumer`) выполняются в едином event loop без блокировки потоков.
